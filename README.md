# Library-Management-System-Java

# Overview

This project is a console-based Library Management System developed using Java. It allows users to perform basic library operations such as adding books, viewing available books, issuing books, and returning books.

# Features

* Add new books to the system
* View all books with availability status
* Issue books to users
* Return issued books
* Menu-driven interface for easy interaction

# Tech Stack

* Java
* OOP Concepts (Classes, Objects, Encapsulation)
* ArrayList

# How to Run

1. Compile the program:
   javac LibraryManagement.java
2. Run the program:
   java LibraryManagement

# Project Structure

* LibraryManagement.java → main program file
